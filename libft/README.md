## Description

This project was created to help practice and understand the fundamental concepts of core C functions before applying them in real-world scenarios. It aims to build a deep understanding of standard C operations and introduces new data structures such as singly linked lists.

The library is divided into three main parts:
- **Part 1 - Libc Functions:** Re-implementation of standard C library functions (e.g., ft_strlen, ft_memcpy, ft_strchr).
- **Part 2 - Additional Functions:** Utility functions primary focused on string manipulation, memory allocation, and file descriptors (e.g., ft_substr, ft_split, ft_itoa).
- **Part 3 - Linked List Functions:** Functions designed for creating, adding, deleting, and manipulating singly linked lists (t_list).

## Instructions

- make or make all: Compiles all source files and creates the static library libft.a.
- make clean: Removes all compiled object (.o) files.
- make fclean: Removes all compiled object (.o) files and the libft.a binary.
- make re: Recompiles the entire project from scratch (fclean + all).
